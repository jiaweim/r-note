# 使用 ggtree 对系统发育树进行可视化与注释

下面演示如何使用 `ggtree`（`ggplot2` 包的扩展包）来对系统发育树进行可视化和注释。这里的许多示例均改编自 `ggtree` 的官方使用指南（vignettes）。

本节课假设你已经具备 R 语言的基础知识，熟悉数据框（data frames），掌握使用 `dplyr` 和 `%>%`（管道操作符）进行数据操作，并且最重要的是，熟悉使用 `ggplot2` 进行数据可视化。

本节课**不涉及**生成系统发育树的方法和软件，也**不涉及**如何解读系统发育树。这里提供了一个关于“如何阅读系统发育树”的简要入门指南，强烈建议你在开始本节课之前先进行复习，但这并非详尽无遗的指南。全基因组测序使得对整个基因组进行检测成为可能；基于此，目前已有许多方法和软件工具，能够利用未组装的测序序列（reads）、草图组装/重叠群（contigs）或完整的基因组序列，通过基于 SNP 或基于基因的系统发育分析来进行比较基因组学研究。这些方法超出了本节课的讨论范围。
