# base::cat

@since 2026-10-16⭐
@author Jiawei Mao
***
拼接并输出对象。相比 `print`，`cat` 执行的类型转换更少。

```r
cat(... , file = "", sep = " ", fill = FALSE, labels = NULL,
    append = FALSE)
```

## 参数

### ...

R 对象（支持类型见“详细说明”）。

### file

`connection` 或输出文件名（字符串）。默认 `""` 输出到控制台；可被 `sink` 重定向。

### sep

字符串向量，添加在每个元素后面（最后一个除外）。`sep` 的元素会依次使用，并根据需要进行循环。

### fill

逻辑值或正数，用于控制自动分行：

- 默认 `FALSE`，只识别 `"\n"` 换行符；
- `TREU` 则按打印宽度 `options("width")` 自动换行；`fill` 为数值时代表行宽；
- 仅在元素之间插入换行符，超长字符串不自动换行（即使超过 `fill`）；
- 非正数 `fill` 值被忽略并给出警告。

### labels

字符串向量，输出行标签；`fill=FALSE` 时忽略该参数。

### append

逻辑值，当参数 `file` 是文件名（不是连接或 `"|cmd"`）时有效。`TRUE` 时追加写入；`FALSE` 则覆盖原文件。

## 详细说明

`cat` 适合在自定义函数内输出内容：先把参数转换为字符向量，拼接后在每个元素后插入 `sep`（最后一个除外），再输出。

仅在显式写入  `"\n"` ，或开始 `fill` 自动分行时才输出换行符。

如果 `file` 已打开的可写入连接，则从当前位置写入；未打开则临时以 `"wt"` 模式打开，写完关闭。

仅支持原子向量、名称、NULL 与零长度向量（无输出）：

- 字符串原样输出，不像 `print.default` 会转义不可打印字符与反斜杠
- 如果想使用 `cat` 输出编码后的字符串，请使用 `encodeString`

其他类型的 R 对象在传入 `cat` 前应该先进行转换（例如，通过 `as.character` 或 `format`）。这包括因子（factors），它们会被作为整数向量输出。

`cat` 转换数值/复数的方式与 `print` 相同，因此受 `options("digits")` 和 `options("scipen")` 影响；`cat` 使用每个元素所需的最小字段宽度，而不是对所有元素使用相同的字段宽度。

## 返回值

无（不可见的 `NULL`）。

## 注意

如果 `sep` 的任何元素包含换行符，则在每个向量元素之后输出一个元素，并且仅在最后一个元素之后输出换行符。条目会根据需要进行循环。

## 另见

`print`、`format` 以及拼接成字符串的 `paste`。

## 示例

- 默认输出到控制台，`sep` 默认为空格

```R
> iter <- stats::rpois(1, lambda = 10)
> cat("iteration = ", iter <- iter + 1, "\n")
iteration =  14 
```

- 自动换行，并添加行标签

```R
> cat(paste(letters, 100* 1:26), fill = TRUE, labels = paste0("{", 1:10, "}:"))
{1}: a 100 b 200 c 300 d 400 e 500 f 600 g 700 h 800 i 900 j 1000 k 1100 l 1200 
{2}: m 1300 n 1400 o 1500 p 1600 q 1700 r 1800 s 1900 t 2000 u 2100 v 2200 w 2300 
{3}: x 2400 y 2500 z 2600
```
