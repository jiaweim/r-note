## 1. S3 系统

S3 指的是 R 语言内置的一种类（class）系统。该系统决定了 R 如何处理不同类的对象。某些 R 函数会查找对象的 S3 类，然后根据类的不同做出不同的响应。

`print` 函数就是一个典型的例子。当你打印一个数值型向量时，`print` 会显示一个数字：

```r
num <- 1000000000
print(num)
## 1000000000
```

但是，如果你给这个数字赋予 S3 类 `POSIXct` 和 `POSIXt`，`print` 就会将其显示为时间：

```r
class(num) <- c("POSIXct", "POSIXt")
print(num)
## "2001-09-08 19:46:40 CST"
```

只要你使用了带有类的对象，就会接触到 S3 系统。S3 的行为初看起来可能有些奇怪，但一旦你熟悉了它，就很容易预测它的表现。

R 的 S3 系统主要围绕三个核心组件构建：属性（attributes，尤其是 `class` 属性）、泛型函数（generic functions）和方法（methods）。

## 2. 属性

许多 R 对象都带有属性。属性是一些被赋予名称并附加到对象上的额外信息。属性不会影响对象的值，而是作为一种元数据（metadata）依附于对象，供 R 在处理该对象时使用。例如，数据框（data frame）会将其行名和列名存储为属性。数据框还会将其类（class）——即 `"data.frame"`——作为属性存储。

你可以使用 `attributes` 函数查看对象的属性。如果你在“项目 2：扑克牌（Project 2: Playing Cards）”中创建的 `deck` 数据框上运行 `attributes`，你会看到：

$row.names

在处理属性时，R 的态度非常“放任自流（laissez-faire）”。它允许你为对象添加任何属性，只有当某个函数需要查找某个属性却发现它不存在时，R 才会报错。

你可以使用 `attr` 函数为对象添加任何通用属性；同样也可以使用 `attr` 来查找对象中任何属性的值。让我们看看这在 `one_play`（即我们玩一次老虎机的结果）上是如何工作的：

```r
one_play <- play()
one_play
## 0

attributes(one_play)
## NULL
```

`attr` 接受两个参数：一个 R 对象和一个属性名称（以字符串形式）。要为 R 对象赋予指定名称的属性，只需将一个值赋给 `attr` 的输出即可。让我们给 `one_play` 添加一个名为 `symbols` 的属性，该属性包含一个字符串向量：

```r
attr(one_play, "symbols") <- c("B", "0", "B")

attributes(one_play)
## $symbols
## [1] "B" "0" "B"
```

要查找任何属性的值，只需向 `attr` 提供一个 R 对象和你想查找的属性名称：

```r
attr(one_play, "symbols")
## "B" "0" "B"
```

如果你给原子向量（如 `one_play`）添加属性，R 通常会在向量的值下方显示该属性。但是，如果该属性改变了向量的类，R 可能会以全新的方式显示向量中的所有信息（正如我们在 `POSIXct` 对象中看到的那样）：

```r
one_play
## [1] 0
## attr(,"symbols")
## [1] "B" "0" "B"
```

通常情况下，除非你赋予属性的名称是 R 函数会主动查找的名称（如 `names` 或 `class`），否则 R 会忽略对象的属性。例如，当你对 `one_play` 进行操作时，R 会忽略它的 `symbols` 属性：

```r
one_play + 1
##  1
## attr(,"symbols")
##  "B" "0" "B"
```

**练习 10.1（添加属性）** 修改 `play` 函数，使其返回一个奖金，并将与该奖金关联的符号作为名为 `symbols` 的属性附加其上。同时，删除冗余的 `print(symbols)` 调用：

```r
play <- function() {
  symbols <- get_symbols()
  print(symbols)
  score(symbols)
}
```

**解答**：你可以通过捕获 `score(symbols)` 的输出并为其分配属性来创建新版本的 `play`。然后 `play` 可以返回这个增强版的输出：

```r
play <- function() {
  symbols <- get_symbols()
  prize <- score(symbols)
  attr(prize, "symbols") <- symbols
  prize
}
```

现在，`play` 会同时返回奖金和与该奖金关联的符号。结果看起来可能不太美观，但当我们将其复制到新对象时，符号会与奖金绑定在一起。我们可以稍后再处理显示格式的美化：

```r
play()
## [1] 0
## attr(,"symbols")
## [1] "B"  "BB" "0" 
 
two_play <- play()
 
two_play
## [1] 0
## attr(,"symbols")
## [1] "0" "B" "0"
```

你也可以使用 `structure` 函数一步生成奖金并设置其属性。`structure` 会创建一个带有一组属性的对象。`structure` 的第一个参数应该是一个 R 对象或一组值，其余参数应该是 `structure` 要添加到对象中的命名属性。你可以为这些参数指定任何你喜欢的名称。`structure` 会按照你提供的参数名称将这些属性添加到对象中：

```r
play <- function() {
  symbols <- get_symbols()
  structure(score(symbols), symbols = symbols)
}

three_play <- play()
three_play
##  0
##  attr(,"symbols")
##  "0"  "BB" "B" 
```

既然你的 `play` 输出包含了一个 `symbols` 属性，你能用它做什么呢？你可以编写自己的函数来查找并使用该属性。例如，下面的函数会查找 `one_play` 的 `symbols` 属性，并用它以一种美观的方式显示 `one_play`。我们将使用这个函数来显示老虎机的结果，所以让我们花点时间研究一下它的功能：

```r
slot_display <- function(prize){

  # extract symbols（提取符号）
  symbols <- attr(prize, "symbols")

  # collapse symbols into single string（将符号折叠为单个字符串）
  symbols <- paste(symbols, collapse = " ")

  # combine symbol with prize as a character string（将符号与奖金组合为字符串）
  # \n is special escape sequence for a new line (i.e. return or enter)
  # \n 是表示换行的特殊转义字符（即回车或 Enter 键）
  string <- paste(symbols, prize, sep = "\n$")

  # display character string in console without quotes（在控制台中不带引号显示字符串）
  cat(string)
}

slot_display(one_play)
## B 0 B
## $0
```

该函数期望接收一个像 `one_play` 这样的对象，它既包含一个数值，又包含一个 `symbols` 属性。函数的第一行会查找 `symbols` 属性的值，并将其保存为名为 `symbols` 的对象。下面创建一个 `symbols` 示例对象，以便了解函数其余部分的作用。我们可以直接使用 `one_play` 的 `symbols` 属性来完成这项工作。`symbols` 将是一个包含三个字符串的向量：

```r
symbols <- attr(one_play, "symbols")

symbols
## "B" "0" "B"
```

接下来，`slot_display` 使用 `paste` 将 `symbols` 中的三个字符串合并为一个单独的字符串。当你向 `paste` 提供 `collapse` 参数时，它会将字符串向量合并为单个字符串，并用 `collapse` 的值作为分隔符。因此，`symbols` 变成了 `B 0 B`（三个字符串由空格分隔）：

```r
symbols <- paste(symbols, collapse = " ")

symbols
## "B 0 B"
```

然后，使用 `paste` 将 `symbols` 与 `prize` 的值组合在一起。当你向 `paste` 提供 `sep` 参数时，它会将多个独立的对象组合为一个字符串。例如，在这里，`paste` 会将 `symbols` 中的字符串 `B 0 B` 与 `prize` 中的数字 `0` 组合起来。`paste` 会使用 `sep` 参数的值来分隔新字符串中的输入内容。在这里，该值是 `\n$`，所以我们的结果看起来会像 `"B 0 B\n$0"`：

```r
prize <- one_play
string <- paste(symbols, prize, sep = "\n$")

string
## "B 0 B\n$0"
```

`slot_display` 的最后一行对新的字符串调用了 `cat`。`cat` 类似于 `print`；它会在命令行上显示其输入内容。但是，`cat` 不会用引号将输出括起来。`cat` 还会将每个 `\n` 替换为换行符。最终结果就是我们看到的那样。请注意，它的显示效果完全符合我之前在“程序（Programs）”一章中建议的 `play` 输出样式：

```r
cat(string)
## B 0 B
## $0
```

你可以使用 `slot_display` 手动清理 `play` 的输出：

```r
slot_display(play())
## C B 0
## $2

slot_display(play())
## 7 0 BB
## $0
```

这种清理输出的方法需要你在 R 会话中手动干预（即调用 `slot_display`）。其实有一个函数可以在每次显示时自动清理 `play` 的输出。这个函数就是 `print`，它是一个泛型函数（generic function）。

## 3. 泛型函数

R 使用 `print` 的频率可能比你想象的要高得多：每次 R 在你的控制台窗口中显示结果时，它都会调用 `print`。这个调用是在后台进行的，所以你通常注意不到它。这也解释了为什么 `print` 的输出总是与你在命令行中直接显示对象时看到的结果一模一样：

```r
print(pi)
## 3.141593

pi
## 3.141593


print(head(deck))
##  face   suit value
##  king spades    13
## queen spades    12
##  jack spades    11
##   ten spades    10
##  nine spades     9
## eight spades     8

head(deck)
##  face   suit value
##  king spades    13
## queen spades    12
##  jack spades    11
##   ten spades    10
##  nine spades     9
## eight spades     8


print(play())
##  5
## attr(,"symbols")
##  "B"  "BB" "B" 

play()
##  5
## attr(,"symbols")
##  "B"  "BB" "B" 
```

你可以通过重写 `print` 函数使其看起来像 `slot_display`，从而改变 R 显示老虎机输出的方式。这样一来，R 就会以我们整洁的格式打印输出。你肯定不希望 R 在打印数据框（data frame）、数值向量或任何其他对象时也去调用 `slot_display`。

幸运的是，`print` 不是一个普通函数；它是一个泛型函数（generic function）。这意味着 `print` 的编写方式使其能够在不同的情况下执行不同的操作。你其实已经见识过这种行为了（尽管你可能没有意识到）。当我们查看未分类（unclassed）的 `num` 时，`print` 做了一件事：

```r
num <- 1000000000
print(num)
## 1000000000
```

而当我们给 `num` 赋予一个类之后，它又做了另一件事：

```r
class(num) <- c("POSIXct", "POSIXt")
print(num)
## "2001-09-08 19:46:40 CST"
```

你可以查看 `print` 内部的代码来看看它是如何做到这一点的。你可能会想象，`print` 会查找输入的类属性（class attribute），然后使用 `if` 分支树来选择要显示的输出。如果你是这样想的，那干得漂亮！`print` 确实做了非常类似的事情，只不过它的实现方式要简单得多。

## 4. 方法

当你调用 `print` 时，`print` 实际上会调用一个特殊的函数 `UseMethod`：

```r
print
## function (x, ...) 
## UseMethod("print")
## <bytecode: 0x7ffee4c62f80>
## <environment: namespace:base>
```

`UseMethod` 会检查你提供给 `print` 第一个参数的输入对象的类（class），然后将你的所有参数传递给一个新函数，这个新函数专门用于处理该特定类的输入。例如，当你给 `print` 传递一个 `POSIXct` 对象时，`UseMethod` 会将 `print` 的所有参数传递给 `print.POSIXct`。随后，R 会运行 `print.POSIXct` 并返回结果：

```r
print.POSIXct
## function (x, ...) 
## {
##     max.print <- getOption("max.print", 9999L)
##     if (max.print < length(x)) {
##         print(format(x[seq_len(max.print)], usetz = TRUE), ...)
##         cat(" [ reached getOption(\"max.print\") -- omitted", 
##             length(x) - max.print, "entries ]\n")
##     }
##     else print(format(x, usetz = TRUE), ...)
##     invisible(x)
## }
## <bytecode: 0x7fa948f3d008>
## <environment: namespace:base>
```

如果你给 `print` 传递一个因子（factor）对象，`UseMethod` 会将 `print` 的所有参数传递给 `print.factor`。随后，R 会运行 `print.factor` 并返回结果：

```r
print.factor
## function (x, quote = FALSE, max.levels = NULL, width = getOption("width"), 
##     ...) 
## {
##     ord <- is.ordered(x)
##     if (length(x) == 0L) 
##         cat(if (ord) 
##             "ordered"
## ...
##         drop <- n > maxl
##         cat(if (drop) 
##             paste(format(n), ""), T0, paste(if (drop) 
##             c(lev[1L:max(1, maxl - 1)], "...", if (maxl > 1) lev[n])
##         else lev, collapse = colsep), "\n", sep = "")
##     }
##     invisible(x)
## }
## <bytecode: 0x7fa94a64d470>
## <environment: namespace:base>
```

`print.POSIXct` 和 `print.factor` 被称为 `print` 的**方法（methods）**。就其本身而言，`print.POSIXct` 和 `print.factor` 就像普通的 R 函数一样工作。但是，它们被专门编写出来的目的，是为了让 `UseMethod` 能够调用它们来处理特定类的 `print` 输入。

请注意，`print.POSIXct` 和 `print.factor` 执行的是两种完全不同的操作（另外请注意，我删减了 `print.factor` 中间的代码——它是一个很长的函数）。这正是 `print` 能够在不同情况下执行不同操作的原因。`print` 调用 `UseMethod`，而 `UseMethod` 会根据 `print` 第一个参数的类来调用专门的方法。

你可以通过在泛型函数上调用 `methods` 函数，来查看该泛型函数存在哪些方法。例如，`print` 拥有将近 200 个方法（这可以让你对 R 语言中存在多少个类有个大概的了解）：

```r
methods(print)
##   [1] print.acf*                                   
##   [2] print.anova                                  
##   [3] print.aov*                                     
##  ...                      
## [176] print.xgettext*                              
## [177] print.xngettext*                             
## [178] print.xtabs*
##
##   Nonvisible functions are asterisked
```

这种由**泛型函数、方法和基于类的分派**（dispatch）组成的系统被称为 **S3**，因为它起源于 S 语言的第三个版本（S 语言后来演变成了 S-PLUS 和 R）。许多常见的 R 函数都是 S3 泛型函数，它们与一组类方法配合工作。例如，`summary` 和 `head` 也会调用 `UseMethod`。更基础的函数，如 `c`、`+`、`-`、`<` 等，其行为也类似于泛型函数，只不过它们调用的是 `.primitive` 而不是 `UseMethod`。

S3 系统允许 R 函数针对不同的类表现出不同的行为。你可以利用 S3 系统来格式化你的老虎机输出。首先，给你的输出赋予一个专属的类。然后，为该类编写一个 `print` 方法。为了高效地完成这项工作，你需要稍微了解一下 `UseMethod` 是如何选择要使用的方法函数的。

### 4.1 方法分派

`UseMethod` 使用一种非常简单的系统来将方法与函数进行匹配。

每个 S3 方法的名称都由两部分组成。名称的第一部分指的是该方法所配合工作的函数，第二部分指的是类。这两部分之间用一个英文句号（`.`）分隔。例如，用于处理函数的 `print` 方法被称为 `print.function`；用于处理矩阵的 `summary` 方法被称为 `summary.matrix`。以此类推。

当 `UseMethod` 需要调用一个方法时，它会搜索具有正确 S3 命名风格的 R 函数。该函数本身不需要有什么特别之处，只要名称正确即可。

你可以通过编写自己的函数并赋予其有效的 S3 命名风格来参与这个系统。例如，让我们给 `one_play` 赋予一个专属的类。类的名称叫什么并不重要，R 会将任何字符串存储在 `class` 属性中：

```r
class(one_play) <- "slots"
```

现在，让我们为 `slots` 类编写一个 S3 `print` 方法。这个方法不需要做任何特别的事情——它甚至不需要打印 `one_play` 本身。但是，它的名称必须是 `print.slots`，否则 `UseMethod` 将无法找到它。此外，该方法还必须接受与 `print` 相同的参数，否则当 R 尝试将参数传递给 `print.slots` 时会报错：

```r
args(print)
## function (x, ...) 
## NULL

print.slots <- function(x, ...) {
  cat("I'm using the print.slots method")
}
```

我们的方法起作用了吗？是的，不仅如此，R 还会使用该 `print` 方法来显示 `one_play` 的内容。由于这个方法没什么实际用处，我打算将其删除。稍后你将有机会编写一个更好的方法：

```r
print(one_play)
## I'm using the print.slots method

one_play
## I'm using the print.slots method

rm(print.slots)
```

有些 R 对象具有多个类。例如，`Sys.time` 的输出就有两个类。那么 `UseMethod` 会使用哪个类来寻找 `print` 方法呢？

```r
now <- Sys.time()
attributes(now)
## $class
## [1] "POSIXct" "POSIXt" 
```

`UseMethod` 会首先寻找与对象类向量中列出的第一个类相匹配的方法。如果 `UseMethod` 找不到，它会继续寻找与第二个类相匹配的方法（如果对象的类向量中还有更多类，则依此类推）。

如果你给 `print` 传递一个没有对应 `print` 方法的对象（无论是一个类还是多个类），`UseMethod` 会调用 `print.default`，这是一个专门编写用来处理一般情况的特殊方法。

让我们利用这个系统为老虎机的输出编写一个更好的 `print` 方法。

**练习 10.2（编写一个 Print 方法）** 为 `slots` 类编写一个新的 `print` 方法。该方法应调用 `slot_display` 以返回格式美观的老虎机输出。

这个方法的名称必须是什么？

**解答**：编写一个优秀的 `print.slots` 方法其实出奇地简单，因为我们在编写 `slot_display` 时已经完成了所有困难的工作。例如，以下方法就能起作用。只需确保该方法的名称是 `print.slots`，以便 `UseMethod` 能找到它；同时确保它接受与 `print` 相同的参数，这样 `UseMethod` 就能顺利地将这些参数传递给 `print.slots`：

```r
print.slots <- function(x, ...) {
  slot_display(x)
}
```

现在，R 会自动使用 `slot_display` 来显示 `slots` 类的对象（并且仅显示 `slots` 类的对象）：

```r
one_play
## B 0 B
## $0
```

让我们确保老虎机的每一段输出都具有 `slots` 类。

**练习 10.3（添加一个类）** 修改 `play` 函数，使其将 `slots` 分配给输出的 `class` 属性：

```r
play <- function() {
  symbols <- get_symbols()
  structure(score(symbols), symbols = symbols)
}
```

**解答**：你可以在设置 `symbols` 属性的同时设置输出的 `class` 属性。只需在 `structure` 调用中添加 `class = "slots"` 即可：

```r
play <- function() {
  symbols <- get_symbols()
  structure(score(symbols), symbols = symbols, class = "slots")
}
```

现在，我们的每一次老虎机游戏输出都将具有 `slots` 类：

```r
> class(play())
[1] "slots"
```

因此，R 会以正确的老虎机格式来显示它们：

```r
> play()
B B DD
$0
> play()
BBB BBB B
$5
```

## 5. 类（Classes）

你可以使用 S3 系统在 R 中创建一个健壮的新对象类。这样一来，R 就能以一致且合理的方式处理你创建的类的对象。要创建一个类，你需要：

1. 为你的类选择一个名称。
2. 为你的类的每个实例分配一个 `class` 属性。
3. 为任何可能会使用你的类对象的泛型函数编写类方法。

许多 R 包都是基于以类似方式构建的类。虽然这项工作原理简单，但实际操作起来可能并不容易。

你可以通过 `methods` 函数的 `class` 参数来调用某个类的方法，该参数需要传入一个字符串。`methods` 会返回为该类编写的所有方法。请注意，如果某些方法包含在未加载的 R 包中，`methods` 将无法显示它们：

```r
methods(class = "factor")
##  [1] [.factor             [[.factor           
##  [3] [[<-.factor          [<-.factor          
##  [5] all.equal.factor     as.character.factor 
##  [7] as.data.frame.factor as.Date.factor      
##  [9] as.list.factor       as.logical.factor   
## [11] as.POSIXlt.factor    as.vector.factor    
## [13] droplevels.factor    format.factor       
## [15] is.na<-.factor       length<-.factor     
## [17] levels<-.factor      Math.factor         
## [19] Ops.factor           plot.factor*        
## [21] print.factor         relevel.factor*     
## [23] relist.factor*       rep.factor          
## [25] summary.factor       Summary.factor      
## [27] xtfrm.factor        
## 
##    Nonvisible functions are asterisked
```

这个输出表明了创建一个健壮且行为良好的类需要多少工作量。通常，你需要为每一个基本的 R 操作都编写一个类方法。

考虑一下你马上就会面临的两个挑战。首先，当 R 将多个对象组合成一个向量时，它会丢弃属性（如 `class`）：

```r
play1 <- play()
play1
## B BBB BBB
## $5

play2 <- play()
play2
## 0 B 0
## $0

c(play1, play2)
## [1] 5 0
```

在这里，R 停止使用 `print.slots` 来显示该向量，因为组合后的向量 `c(play1, play2)` 不再具有 `"slots"` 的 `class` 属性。

其次，当你对对象进行子集提取时，R 也会丢弃对象的属性（如 `class`）：

```r
play1[1]
## [1] 5
```

你可以通过编写 `c.slots` 方法和 `[.slots` 方法来避免这种行为，但随后困难会迅速累积。如何将多次游戏的 `symbols` 属性合并为一个包含多个 `symbols` 属性的向量？你该如何修改 `print.slots` 来处理输出向量？这些挑战留给你去探索。不过，作为一名数据科学家，你通常不需要尝试这种大规模的程序设计。

在我们的例子中，当我们将多个 `slots` 对象组合成一个向量时，让它们退化为单纯的奖金数值，是非常方便的。

## 6. S3 与调试

如果你试图理解 R 函数的内部机制，S3 系统有时会让人感到有些恼火。如果一个函数的代码主体中包含对 `UseMethod` 的调用，你很难直接看出它到底做了什么。现在你已经知道 `UseMethod` 会调用特定类的方法，你可以直接搜索并检查该方法。这个方法的命名通常遵循 `<函数名.类名>` 的语法，或者可能是 `<函数名.default>`。你也可以使用 `methods` 函数来查看与某个函数或某个类相关联的方法。

## 7. S4 与 R5

R 还包含另外两种用于创建特定类行为的系统，它们被称为 S4 和 R5（或引用类，reference classes）。这两个系统的使用难度比 S3 大得多，或许正因如此，它们在实际中相对少见。不过，它们提供了 S3 所不具备的安全保障机制。如果你想深入了解这些系统（包括如何编写和使用你自己的泛型函数），我推荐 Hadley Wickham 所著的《Advanced R Programming》（高级 R 编程）一书。

## 8. 总结

在 R 中，值（values）并不是存储信息的唯一途径，函数也不是创造独特行为的唯一方式。你同样可以通过 R 的 S3 系统来实现这两点。S3 系统提供了一种在 R 中创建对象特定行为的简单方法。换句话说，它是 R 语言**对面向对象编程**（OOP）的实现。该系统通过泛型函数来实现：这些函数会检查输入的类属性，并调用特定类的方法来生成输出。许多 S3 方法会查找并使用存储在对象属性中的附加信息。许多常见的 R 函数都是 S3 泛型函数。

对于数据科学家而言，R 的 S3 系统在计算机科学任务中的帮助比在数据科学任务中更大，但理解 S3 依然能帮助你在作为数据科学家处理 R 语言工作时更好地排查问题。
