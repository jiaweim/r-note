# 项目 3：老虎机（Slot Machine）

2026-08-28⭐
@author Jiawei Mao
***
老虎机是现代赌场中最受欢迎的游戏。老虎机看起来就像一台旁边带有一根拉杆的街机游戏。只需支付少量费用，你就可以拉动拉杆，机器会随机生成三个符号的组合。如果出现正确的组合，你就能赢得奖品。

老虎机能为赌场带来丰厚的利润，因为它们的赔付率非常低。在许多游戏（如二十一点和轮盘赌）中，赌场占据的优势微乎其微。从长远来看，赌客在这些游戏上每投入一美元，赌场通常会返还 97 到 98 美分的奖金。而在老虎机上，赌场通常只返还 90 到 95 美分——剩下的钱就归赌场所有了。如果这听起来有些狡猾，但老虎机是赌场中最受欢迎的游戏之一，似乎很少有人介意。而且，如果你考虑到各州彩票的赔付率通常只有 50% 左右，老虎机看起来似乎也没那么糟。

在这个项目中，你将构建一台真实可用的老虎机，其模型基于加拿大马尼托巴省的一些真实视频彩票终端机（Video Lottery Terminals）。这些终端机在 20 世纪 90 年代曾引发过一场丑闻。通过编写一个程序来重现这些老虎机，你将揭开这场丑闻的真相。接着，你将进行一些计算和模拟，以揭示这些机器的真实赔付率。

这个项目将教你如何在 R 语言中编写程序和运行模拟。你还将学习如何：

- 使用实用的策略来设计程序
- 使用 `if` 和 `else` 语句来告诉 R 在何时执行何种操作
- 创建查找表（lookup tables）以寻找对应的值
- 使用 `for`、`while` 和 `repeat` 循环来自动执行重复性操作
- 使用 S3 方法，即 R 语言中的面向对象编程（Object-Oriented Programming）版本
- 测量 R 代码的运行速度
- 编写高效的、向量化的 R 代码
