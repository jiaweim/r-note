五年前本书第一版出版时，“数据科学”这个词才刚刚进入大众词汇。而今，在科研、新闻和高科技行业，它已经成了避不开的话题。这背后有许多相互关联的发展因素：人们认识到理解海量数据能带来切实好处；关于如何开展数据科学的优质教育资源变得更丰富易得；各种工具不断进化，入门门槛更低。

本书旨在帮你通过数据可视化深入理解数据，并协助你将这种理解传达给他人。数据分析就是将原始数据转化为他人脑海中的想法，而数据可视化是实现这一目标的关键技术之一。人类拥有高度发达的视觉模式识别系统，而数据可视化正是一种高效利用这些视觉系统、将量化信息植入他人脑海的方法。

本书每个技巧都包含一个具体问题和相应的解决方案。多数情况下，我提供的方案不是 R 中的唯一方法，但通常是最佳方法。R 语言之所以广受欢迎，原因之一就是它有大量附加包。虽然用于数据可视化的 R 包有很多，但本书主要用 ggplot2。

本书不是 R 数据可视化的全面手册，但希望能帮你做出你脑海中构想的图形。如果你不确定要做什么图，浏览本书或许能为你带来一些灵感。

## 0.1 实用技巧

本书面向具有 R 基础的读者。书中每个技巧展示如何完成特定任务，并尽量采用简单示例，方便你理解并灵活应用到你自己的实际问题中。

## 0.2 软件与平台说明

本书多数技巧使用 `ggplot2` 和 `dplyr`，二者都属于 `tidyverse`。`tidyverse` 是一系列 R 包的集合，旨在简化数据处理。部分技巧需要使用新版 `ggplot2`（3.0.0+），因此需要较新版本的 R。最新版 R 可从 https://www.r-project.org/ 获取。

> [!NOTE]
>
> **提示** 即使只对 `ggplot2` 有浅显了解，也可以直接使用本书技巧。若想深入理解工作原理，请参阅附录 A。

安装 R 后，再安装所需包。除了 `tidyverse` 外，还需要安装 `gcookbook`，它包含本书许多示例用到的数据集。安装代码：

```r
install.packages("tidyverse")
install.packages("gcookbook")
```

安装时可能需要选 CRAN镜像。任选即可，建议选近的，下载更快。

安装好包，每个 R 会话都需要加载 `ggplot2` 和 `dplyr`：

```r
library(ggplot2)
library(dplyr)
```

本书代码默认已加载 `ggplot2` 和 `dplyr`。若报错：

```text
Error: could not find function "ggplot"
```

说明忘记加载 `ggplot2`。

本书代码在 macOS、Linux 和 Windows 上均可运行。但在生成位图文件时平台间会存在一些差异，详见第 14 章。
