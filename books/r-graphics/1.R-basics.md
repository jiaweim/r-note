本章介绍 R 基础：包的安装与使用、数据加载。

本书多数技巧需安装 `ggplot2`、`dplyr` 和 `gcookbook` （`gcookbook` 提供示例数据集，实际工作中并非必需）。安装包：

```r
install.packages("tidyverse")
install.packages("gcookbook")
```

每次 R 会话运行示例前加载：

```r
library(tidyverse)
library(gcookbook)
```

运行 `library(tidyverse)` 会同时加载 `ggplot2`、`dplyr` 等。若想精简，可仅加载必需包：

```r
library(ggplot2)
library(dplyr)
library(gcookbook)
```

> [!TIP]
>
> 若您想深入了解 `ggplot2`，请参阅附录 A。

**R 包**是函数和/或数据的集合，打包在一起便于分发。安装包可扩展 R 功能。R 包通过仓库分发，CRAN 是主要仓库，另外还有专门提供基因组数据相关包的 Bioconductor 等。

`tidyverse` 是一组共享统一设计理念的包，它让数据处理和可视化更简单。本书主要使用 `tidyverse`。

若从未使用过 `tidyverse`，建议阅读本章技巧 1.7，以理解管道操作符：`%>%`。

## 1.1 安装包

### 1.1.1 问题

从 CRAN 安装一个包。

### 1.1.2 解决方案

使用 `install.packages()` ，传入包名。安装 ggplot2：

```r
install.packages("ggplot2")
```

系统可能提示选择下载镜像。通常选第一个 `https://cloud.r-project.org/`，它是一个基于云端的镜像站点，在全球各地都有节点。

### 1.1.3 讨论

一次安装多个包，传入包名向量：

```r
install.packages(c("ggplot2", "gcookbook", "MASS", "dplyr"))
```

R 会自动安装该包所依赖的所有其他包。

CRAN（R 语言综合档案网络）是 R 的默认包仓库，在全球许多服务器上都有镜像。另外还有其他包仓库，如 Bioconductor就是一个专门提供基因组数据分析相关包的仓库。

## 1.2 加载包

### 1.2.1 问题

加载一个已安装的包。

### 1.2.2 解决方案

用 `library()`，传入包名。加载 ggplot2：

```r
library(ggplot2)
```

该包必须已安装。

### 1.2.3 讨论

本书多数技巧在运行前需加载相应包，以获得绘图功能（如 `ggplot2`）或示例数据集（如 `MASS `和 `gcookbook`）。

R 中 “包（package）”和“库（library）”这两个术语常被混用。我们用 `library()` 加载包，但包不是库。库（Library）是包含一组包的目录。例如系统级库以及用户级库。

## 1.3 升级包

### 1.3.1 问题

升级已安装的包。

### 1.3.2 解决方案

运行：

```r
update.packages()
```

它会对每个可升级包逐个向你确认。若不想被询问，用：

```r
update.packages(ask = FALSE)
```

### 1.3.3 讨论

包作者会不断发布包含错误修复和新功能的新版本，因此保持更新通常是个好习惯。但新版本偶尔也可能引入 bug 或细微行为变化。

## 1.4 加载分隔文本文件

### 1.4.1 问题

从分隔文本文件加载数据。

### 1.4.2 解决方案

读取逗号分隔值（CSV）文件最常见：

```r
data <- read.csv("datafile.csv")
```

也可以使用 `readr` 包的 `read_csv()`（注意这里是下划线），它比 `read.csv()` 快得多。

### 1.4.3 讨论

数据文件格式多样，因此加载方法选项也多。

- 第一行没有表头

```r
data <- read.csv("datafile.csv", header = FALSE)
```

- 生成的数据框（data frame）的列名为 V1、V2 等，可手动重命名：

```r
names(data) <- c("Column1", "Column2", "Column3")
```

- 用 `sep` 设置分隔符。空格分隔用 `sep = " "`，制表符用 `\t`：

```r
data <- read.csv("datafile.csv", sep = "\t")
```

默认数据中的字符串会转为因子（factor）。假设文件：

```text
"First","Last","Sex","Number"
"Currer","Bell","F",2
"Dr.","Seuss","M",49
"","Student",NA,21
```

`read.csv()` 会把 First 和 Last 列存为因子，尽管作为字符串更为合理。可用 `stringsAsFactors = FALSE` 保留为字符串：

```r
data <- read.csv("datafile.csv", stringsAsFactors = FALSE)

# 转换为因子
data$Sex <- factor(data$Sex)

str(data)
#> 'data.frame': 3 obs. of 4 variables:
#> $ First : chr "Currer" "Dr." ""
#> $ Last : chr "Bell" "Seuss" "Student"
#> $ Sex : Factor w/ 2 levels "F","M": 1 2 NA
#> $ Number: int 2 49 21
```

也可以保留默认的因子设置，之后再单独把某些列转为字符型。

### 1.4.4 另请参阅

`read.csv()` 是 `read.table()` 的便捷封装。如果需要更多控制，请查阅 `?read.table`。

## 1.5 从 Excel 文件加载数据

### 1.5.1 问题

从 Excel 文件加载数据。

### 1.5.2 解决方案

用 `readxl` 包的 `read_excel()` 读取 Excel 的 `.xls` 和 `.xlsx` 文件。以下读取 Excel 文件的第一个工作表：

```r
# 只需安装一次
install.packages("readxl")

library(readxl)
data <- read_excel("datafile.xlsx", 1)
```

### 1.5.3 讨论

使用 `read_excel()` 时，可用数字序号（`sheetIndex`）或名称（`sheetName`）指定加载的工作表：

```r
data <- read_excel("datafile.xls", sheet = 2)

data <- read_excel("datafile.xls", sheet = "Revenues")
```

默认使用第一行作为列名。如果不想第一行作为列名，则设 `col_names = FALSE`。此时列名自动变为 X1、X2 等。

`read_excel()` 默认自动推断列类型，也可以用 `col_types` 手动指定；将列类型指定为 `"blank"` 表示丢弃该列：

```r
# 丢弃第一列，并指定接下来三列的数据类型
data <- read_excel("datafile.xls", col_types = c("blank", "text", "date", "numeric"))
```

### 1.5.4 另请参阅

更多选项请参阅 `?read_excel`。

其他读取 Excel 文件的包:

- `gdata` 的 `read.xls()` 读取 `.xls` 文件
- `xlsx` 的 `read.xlsx()` 读取 `.xlsx` 文件

注意：`read.xls()` 需要安装 Java，`read.xlsx()` 需要安装 Perl。

## 1.6 从 SPSS/SAS/Stata 文件加载数据

### 1.6.1 问题

从 SPSS、SAS、Stata 等统计软件的文件加载数据。

### 1.6.2 解决方案

用 `haven` 的 `read_sav()` 读取 SPSS 文件：

```r
# 首次使用时需安装
install.packages("haven")

library(haven)
data <- read_sav("datafile.sav")
```

### 1.6.3 讨论

`haven` 还提供：

- `read_sas()`：读取 SAS 文件
- `read_dta()`：读取 Stata 文件

`foreign` 是 `haven` 的一个替代选择，同样支持 SPSS 和 Stata 文件，但功能陈旧：仅支持 Stata 12 及以下，而 `haven` 支持到 Stata 14（撰写本书时的最新版）。

`foreign` 还支持：

- `read.octave()`：Octave 和 MATLAB
- `read.systat()`：SYSTAT
- `read.xport()`：SAS XPORT
- `read.dta()`：Stata
- `read.spss()`：SPSS

### 1.6.4 另请参阅

运行 `ls("package:foreign")` 查看 `foreign` 的所有函数。

## 1.7 使用管道操作符 %>% 串联函数

### 1.7.1 问题

想依次调用多个函数，并保持代码的可读性。

### 1.7.2 解决方案

用 `%>%`（管道操作符）。例如：

```r
library(dplyr) # 管道操作符由 dplyr 包提供

morley # 查看 morley 数据集
#>     Expt Run Speed
#> 001    1   1   850
#> 002    1   2   740
#> 003    1   3   900
#>  ...<94 more rows>...
#> 098    5  18   800
#> 099    5  19   810
#> 100    5  20   870

morley %>%
  filter(Expt == 1) %>%
  summary()
#>       Expt        Run            Speed     
#>  Min.   :1   Min.   : 1.00   Min.   : 650  
#>  1st Qu.:1   1st Qu.: 5.75   1st Qu.: 850  
#>  Median :1   Median :10.50   Median : 940  
#>  Mean   :1   Mean   :10.50   Mean   : 909  
#>  3rd Qu.:1   3rd Qu.:15.25   3rd Qu.: 980  
#>  Max.   :1   Max.   :20.00   Max.   :1070
```

这段代码将 `morley` 数据集传递给 `dplyr` 的 `filter()` 函数，只保留 `Expt == 1` 的行，再传给 `summary()` 计算汇总统计量。

不用管道操作符，则写成：

```r
summary(filter(morley, Expt == 1))
```

嵌套写法从内向外执行，逻辑正确，但可读性差，嵌套多时更难阅读。

### 1.7.3 讨论

`%>%` 操作符在 `tidyverse` 中广泛使用，把多个函数串联成完整流程。

基本等价关系：

```r
f(x)
# 等价于：
x %>% f()
```

管道操作符将左侧对象作为右侧函数的第一个参数。可用于多函数链式组合调用：

```r
h(g(f(x)))
# 等价于：
x %>%
  f() %>%
  g() %>%
  h()
```

在函数链中，函数书写顺序与实际计算顺序一致。

使用 `<-` 赋值运算符保存运算结果：

```r
x <- x %>%
  f() %>%
  g() %>%
  h()
```

如果函数有额外参数，在使用管道操作符时这些参数顺移到右侧。以下两种写法等价：

```r
filter(morley, Expt == 1)

morley %>% filter(Expt == 1)
```

管道操作符实际上源自 `magrittr` 包，`dplyr` 导入了它，因此调用 `library(dplyr)` 后就可以直接使用。
