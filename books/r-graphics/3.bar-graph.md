# 3. 条形图

条形图是最常用的数据可视化方法之一：x 轴为类别，y 轴为数值。条形图适合比较不同类别的数值，但不适合用来展示数值随时间的变动趋势（时间是连续变量）。

从本章开始，重点介绍使用 ggplot2。使用 ggplot2 不仅更简单，还能绘制出更复杂、精美的图形。

这段关于 R 语言 `ggplot2` 绘图教程的文本，用中文可以这样专业且流畅地表达：

## 3.1 绘制基础条形图

### 3.1.1 问题

绘制条形图：你有一个数据框，其中一列表示 bar 在 x 轴上的位置，另一列表示每个 bar 的垂直高度（y 轴）。

### 3.1.2 解决方案

使用 `ggplot()` 结合 `geom_col()`，指定 x 和 y 变量（图 3.1）：

```R
library(gcookbook) # 加载 gcookbook 以获取 pg_mean 数据集
library(ggplot2)

ggplot(pg_mean, aes(x = group, y = weight)) +
  geom_col()
```

>  **图 3.1**：具有离散 x 轴的数值条形图

### 3.1.3 讨论

当 x 为连续（数值）变量时，条形表现不同：此时，条形不再只出现在实际 x 值处，而是在最小值和最大值之间的每个可能 x 值处都预留位置（图 3.2）。可以使用 `factor()` 将连续变量转换为离散变量。

```R
> BOD # BOD 数据集中没有 Time == 6 的记录
  Time demand
1    1    8.3
2    2   10.3
3    3   19.0
4    4   16.0
5    5   15.6
6    7   19.8
```

```R
> str(BOD) # Time 是数值型（连续）变量
'data.frame':	6 obs. of  2 variables:
 $ Time  : num  1 2 3 4 5 7
 $ demand: num  8.3 10.3 19 16 15.6 19.8
 - attr(*, "reference")= chr "A1.4, p. 270"
```

```R
library(gcookbook)
library(ggplot2)

ggplot(BOD, aes(x = Time, y = demand)) +
  geom_col()
```

<img src="./images/Rplot01.png" alt="Rplot01" style="zoom:50%;" />

> **图 3.2**：具有连续 x 轴的数值条形图

```R
library(gcookbook)
library(ggplot2)

# 使用 factor() 将 Time 转换为离散（分类）变量
ggplot(BOD, aes(x = factor(Time), y = demand)) +
  geom_col()
```

<img src="./images/Rplot02.png" alt="Rplot02" style="zoom:50%;" />

> **图 3.2**：将 x 变量转换为 factor 后的条形图

注意，`BOD` 数据集中没有 `Time = 6`。当 x 为连续变量时，`ggplot2` 使用数值坐标轴，该坐标轴会为范围内所有数值预留空间，因此在 6 处留空位。将 `Time` 转换为 `factor` 后，`ggplot2` 将其视为离散变量，这些值被当作标签而非数值处理，因此不会为最小值和最大值之间所有数值分配空间。

上例中，数据已包含 x 值和 y  两列。如果希望条形高度代表各组案例的计数（频数），见 3.3 节。

条形图默认使用深灰色填充。用 `fill` 设置填充色，用 `colour` 参数设置边框色。图 3.3 使用浅蓝色填充和黑色边框：

```r
library(gcookbook)
library(ggplot2)

ggplot(pg_mean, aes(x = group, y = weight)) +
  geom_col(fill = "lightblue", colour = "black")
```

<img src="./images/Rplot03.png" alt="Rplot03" style="zoom:50%;" />

>  **图 3.3**：所有条形使用统一的填充色和边框色

> [!NOTE]
>
> `ggplot2` 默认使用英式拼写 `colour`，不过美式拼写 `color` 在内部会自动映射为英式拼写，同样有效。
