# S3

## 1. 简介

S3 是 R 语言中第一个也是最简单的面向对象（OO）系统。S3 是非正式的、临时性的，但其极简主义中蕴含着一种独特的美感：你无法从中删减任何部分而依然保留一个有用的面向对象系统。基于这些原因，除非你有充分的理由，否则你应该使用 S3。S3 是 base 和 stats 包中唯一使用的面向对象系统，也是 CRAN 包中最常用的面向对象系统。

S3 极其灵活，这意味着它允许你做一些非常不明智的事情。如果你习惯了 Java 这样严格的编程环境，这可能会让你感到相当害怕，但它赋予了 R 程序员极大的自由度。你可能很难阻止别人做你不想让他们做的事情，但你的用户也永远不会因为你尚未实现某些功能而受到限制。由于 S3 几乎没有内置的约束，因此成功使用它的关键在于你自己施加约束。因此，本章将教你应该始终遵循的约定。

本章的目标是向你展示 S3 系统是如何工作的，而不是教你如何有效地使用它来创建新的类和泛型函数。我建议你将本章的理论知识与 `vctrs` 包中蕴含的实践知识结合起来学习。

**章节大纲**

- **13.2 节**：概述 S3 的所有主要组件：类（classes）、泛型函数（generics）和方法（methods）。你还将学习 `sloop::s3_dispatch()` 函数，我们将在本章中用它来探索 S3 的工作原理。
- **13.3 节**：介绍如何创建新的 S3 类，包括大多数类都应配备的三个函数：构造函数（constructor）、辅助函数（helper）和验证器（validator）。
- **13.4 节**：描述 S3 泛型函数和方法的工作机制，包括方法分派（method dispatch）的基础知识。
- **13.5 节**：讨论 S3 对象的四种主要风格：向量（vector）、记录（record）、数据框（data frame）和标量（scalar）。
- **13.6 节**：演示继承（inheritance）在 S3 中的工作原理，并告诉你需要怎么做才能让一个类“可被子类化（subclassable）”。
- **13.7 节**：本章的结尾部分将讨论方法分派的细节，包括基础类型（base types）、内部泛型函数（internal generics）、组泛型函数（group generics）以及双重分派（double dispatch）。
