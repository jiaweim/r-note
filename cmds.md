# 常用命令



## 工作目录

- 查看工作目录

```R
getwd()
```

- 修改工作目录

Session > Set Working Directory > Choose Directory

### 📂 核心函数

| 函数         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| `getwd()`    | 获取当前工作目录的绝对路径，返回字符向量或 `NULL`            |
| `setwd(dir)` | 设置工作目录为 `dir` 指定的路径，返回切换前的旧路径（不可见） |

### 📁 目录内容查看

| 函数                                    | 说明                                           |
| --------------------------------------- | ---------------------------------------------- |
| `list.files(path, pattern, full.names)` | 列出指定目录下的文件和子目录，支持正则匹配过滤 |
| `dir()`                                 | `list.files()` 的别名，用法完全相同            |

### 📐 路径操作

| 函数                  | 说明                                                     |
| --------------------- | -------------------------------------------------------- |
| `normalizePath(path)` | 将路径标准化为绝对路径（解析符号链接等），确保跨平台兼容 |
| `file.path(...)`      | 跨平台拼接路径，自动使用正确的路径分隔符                 |
| `dirname(path)`       | 提取路径中的目录部分                                     |
| `basename(path)`      | 提取路径中的文件名部分                                   |

### 🔍 文件属性检查

| 函数                | 说明                                             |
| ------------------- | ------------------------------------------------ |
| `file.exists(path)` | 检查文件或目录是否存在                           |
| `file.info(path)`   | 获取文件详细信息（大小、修改时间、是否为目录等） |
| `file.size(path)`   | 获取文件大小（字节）                             |

### 📝 目录创建与删除

| 函数                          | 说明                                                    |
| ----------------------------- | ------------------------------------------------------- |
| `dir.create(path, recursive)` | 创建目录，`recursive = TRUE` 可递归创建多级目录         |
| `unlink(path, recursive)`     | 删除文件或目录，`recursive = TRUE` 可递归删除整个目录树 |

### 💡 实用技巧

- **路径分隔符**：R 中路径统一使用正斜杠 `/`，Windows 下也可用双反斜杠 `\\`，但单反斜杠 `\` 会被当作转义字符。
- **相对路径**：`"./"` 表示当前目录，`"../"` 表示上级目录，推荐在项目中优先使用相对路径以提高可移植性。
- **R Project**：在 RStudio 中创建 `.Rproj` 文件后，打开项目时会自动将工作目录设为项目根目录，是管理路径的最佳实践。

## 库和包

- 查看当前库所在位置

```r
.libPaths()
```

- 查看当前库和库中所含包

```R
lapply(.libPaths(), list.files)
```

- 查看所用 repository

```R
getOption("repos")
```

## renv

```R
# 初始化项目
renv::init() 
renv::init(bare=TRUE) # 初始化空的项目库

# 更新或安装包
renv::install()
renv::update()

# 记录包版本，更新 lockfile
renv::snapshot()

# 安装 lockfile 中记录的包: 恢复项目库
renv::restore()
```
